# 🚀 Server Node Monitor - 企业级全景监控系统 (最终版 PRD)

## 一、 产品概述与架构定位

本系统是一款集 "极速实时性能看板、IT 资产与续费管理、多渠道智能告警" 于一体的现代化基础设施管控平台。

- **探针端 (Agent)：** 基于 .NET 10 Native AOT 编译，打造 10MB 级别、微毫内存占用、无任何系统依赖的跨平台独立二进制文件。
- **服务端 (Master)：** 基于 .NET 10 Web API + SignalR + EF Core (SQLite WAL 模式) 构建高并发、易迁移的数据中枢。
- **前端控制台 (Web UI)：** 采用 vue-naive-admin (Vue 3) 搭建私密管理后台；采用纯流式 HTML/CSS 渲染访客大屏。

## 二、 通信协议：极致压缩与穿透 (Network Layer)

系统抛弃传统 JSON，对大规模节点的网络层进行了极致压缩与内网兼容：

- **MessagePack 二进制协议：** 全面启用 SignalR + MessagePack。通过 `[Key(x)]` 强类型索引抹除所有属性名字段，将数据包压缩为极简的二进制数组，单次心跳包控制在 50 Bytes 内，CPU 序列化开销趋近于零。
- **精简数据契约：** 探针不传 DateTime（服务端接收时实时打时间戳），将 TimeSpan 转为 int，榨干网络带宽。
- **内网代理级联穿透：** 探针原生支持配置 `--proxy` 参数（HTTP/SOCKS5）。无公网的内网机器可通过网关机代理直连公网 Master，探针自身绝对不开放任何监听端口。

## 三、 Agent (探针端) 规范

坚持"无状态、只读、零后门、无下发执行权限"的最高安全原则。

- **高频采集 (每2秒)：** CPU 使用率、物理内存及 Swap 状态、各挂载磁盘容量、实时网卡上下行速率。
- **复杂硬件兼容：**
  - **双路/多路 CPU：** 自动聚合读取全局 CPU 使用率，并在注册时上报真实的 CpuModel（如 2x Intel Xeon）与总逻辑核心数。
- **动态 IP 发现 (针对 DHCP/NAT)：**
  - 探针启动及定时轮询本地 Up 状态的网卡，提取 IPv4/IPv6 内网及公网地址（剔除 127.0.0.1 及无效链路地址）。即使本地是 DHCP，也能拿到最新内网 IP 组，上报给服务端。
- **安全防御：** 强制 AgentKey 鉴权，绝对不包含 OTA（自动更新）模块，杜绝 RCE（远程命令执行）风险。

## 四、 Master (服务端) 核心计算引擎

- **公私网 IP 合并与 GeoIP 识别：**
  - **动态捕获：** 服务端在 SignalR 建立连接的瞬间，捕获真实的远程公网 IP（解决 DHCP 和 NAT 隐藏真实 IP 的问题）。
  - **合并更新：** 将服务端捕获的公网 IP，与探针上报的本地 IP 组进行去重合并，存入数据库。
  - **国家标识：** 基于公网 IP 自动解析国家代码（如 US, SG），并允许管理员在后台手动覆盖。
- **流量精准计费引擎 (Delta 增量法)：**
  - 探针仅上报当前网卡的"历史总流量"。服务端通过计算前后两次心跳的差值 (Delta) 累加月度真实消耗。
  - 完美兼容 VPS 重启（网卡清零）场景。在设定的"账单重置日"自动清零当月计费流量。
- **时序数据降采样 (Downsampling)：**
  - **热数据 (24小时内)：** 每分钟均值。
  - **温数据 (1~7天)：** 每小时均值。
  - **冷数据 (7~30天)：** 每天均值，超 30 天明细自动销毁，确保 SQLite .db 文件体积可控，查询丝滑。
- **插件化告警与防抖机制：**
  - 触发规则：离线超时 (>30s)、流量超标 (>80%)、高负载持续 (>90%)。
  - 防风暴设计：设定连续异常触发阈值；告警发送后进入 30~60 分钟静默冷却期；恢复正常后发送🟢恢复通知。
  - 支持 Telegram Bot 与 Webhook（支持动态配置）。

## 五、 资产与财务管理模块 (Wallos-Lite)

将监控与 VPS 资产管理结合（仅后台可见）。

- **财务台账：** 配置供应商、续费价格、币种（USD/CNY/EUR）、到期时间。
- **双命名隔离：**
  - `AdminRemark`: 后台私密运维备注（如 "核心 DB-勿动"）。
  - `PublicName`: 前台大屏脱敏展示名（如 "HK-Node-01"）。
- **到期巡检：** 每日后台任务自动扫描，距到期 < 7 天触发 TG/Webhook 告警。

## 六、 前端 UI 交互设计

### 6.1 管理后台 (基于 vue-naive-admin)

- **总览大盘：** 资产总数、离线预警节点、即将到期节点、月度固定总支出 (MRR)。
- **节点配置：** CRUD 操作，配置流量限制与重置日，录入续费信息。支持一键生成专属安装脚本。
- **探针视图：** 列表展示服务器国旗、CPU/内存微型进度条、合并后的全量 IP 列表。引入 ECharts 展示节点的 24h/7d/30d 性能折线图。
- **系统设置：** 动态配置通知渠道参数与全局告警阈值。

### 6.2 公开看板 (Public Dashboard)

- **纯实时流式渲染：** 页面加载仅建立 SignalR 连接，无数据库 HTTP 请求。
- **脱敏与视觉：** 节点卡片展示对应国家的国旗 Emoji (🇸🇬, 🇺🇸)。仅展示 PublicName、在线状态与实时性能波浪图。不包含任何 IP、财务、真实主机名等敏感信息。
