# 独立主题与延时探测

用户已确认：参考 Komari 官方默认前端，新增独立主题，并实现节点到指定目标的 ICMP / TCP 探测。

## 展示

主题 `panorama` 使用原生 HTML/CSS/JS 和现有 SDK。提供总览、搜索、状态筛选、卡片/列表、深浅色、移动端，以及节点内线路延时曲线。公开字段仅为公开名称、国家、性能和探测线路名称/协议/测量结果，不公开目标地址、IP、财务或密钥。

## 探测闭环

后台系统设置增加延时探测页，维护至多 16 个目标，每个目标指定节点、公开名称、协议、主机、TCP 端口、10–3600 秒间隔、200–10000 毫秒超时、启用状态。配置保存在现有 SQLite Settings 表内，使用独立管理接口校验。Agent 主动通过 Hub 每 30 秒获取自己的配置，执行内置 ICMP/TCP 测量，不执行 shell，不监听端口，探测走节点直连网络（Master 的代理参数仅控制上报连接）。

新增可独立序列化的配置/结果 MessagePack DTO，保持原心跳不变。每个任务带修订标识，服务端拒绝旧配置、未授权节点、旧连接及过密结果。并发最多 4，所有探测均有超时与取消。ICMP 记录 RTT；TCP 记录 TCP 建连耗时（DNS 在计时前解析）；DNS/权限错误独立于超时。无 ICMP 权限标记不支持，不回退调用外部 ping 程序。

Master 按节点和任务维护最近 60 个结果，只将脱敏结果通过公开 Hub 推送，首连快照包含缓存。未测量、成功、超时、错误、不支持、数据过期、节点离线均区分；失败不画为 0ms。ICMP 丢包率 / TCP 失败率基于窗口内成功、超时及错误样本计算，不支持不计入分母。

本期完成实时闭环，不扩展长期延时存储或告警。旧 Agent 仍可上报性能，新主题无延时数据时显示等待；新 Agent 对旧 Master 的未知方法保持性能上报并提示不支持。
